# 7. 剧情脊柱：里程碑骨架 + 软引力 + 隐藏世界时钟

- 状态：Accepted
- 日期：2026-06-01

## 背景

AIDM 循剧本（[ADR-0002] 把它定为唯一状态写入者；Q11 定它"忠实呈现 + 应对偏离 + 拽回剧情，超逆天骰运除外"）。但整套系统（涌现玩法、玩家自治、兵分两路、不可预测的 AI 队友）是为容纳偏离而建的。需要一个既"忠实剧本"、又不与涌现对冲的脊柱结构。用真实出版模组（如《堕入阿弗纳斯》）的解剖反推：模组 = 章节大纲 + keyed locations + NPC + 遭遇/触发 + 检定 + 分支 + 进度里程碑 + bespoke 机制 + 地图——这恰好可拆进我们已有的数据模型。

## 决策

### 形状与刚性：里程碑骨架（非铁轨、非纯沙盒）
- 脊柱 = 一串**承重的里程碑 beat**（"故事要成为它自己，这几件事必须发生"），**只规定承重节点，不规定节点之间**；之间全是即兴。
- 从种子**先生成粗骨架**，每个里程碑**细节 JIT 充实**；骨架是**活的、可随偏离下游重生成**。

### CampaignBible schema（脊柱 = 模组导入的目标结构）
```
CampaignBible {
  secretTruth                     // DM 私有底牌（不发，[ADR-0002]）
  milestones: [ { goal, enterCue, scenes[], triggers[], branchPoints, levelTarget } ]
  npcs: [persona templates → souls ([ADR-0006])]
  bespokeRules                    // 残差桶，v1 基本留空
}
```
未来"导入正规模组" = 写解析器把模组拆进这些桶。难点（v1 缓做）：bespoke 机制、地图(等 VTT)、散文→触发抽取、版权。

### 软引力阶梯（平时只用底层，全程隐形/diegetic）
1. 被动线索（多撒面包屑，三线索原则）
2. 主动暗示（NPC/事件把线索递明显）
3. **世界时钟**（拖延 → 反派推进/风险升级）—— 核心常备工具
4. **量子挪移**（把内容搬到玩家所在处）
5. 真分叉（超逆天/玩家铁心 → 放弃里程碑，JIT 开新枝）

AI 队友不特殊处理：引力活在虚构里，所有行动者只对虚构反应。漂移由 AIDM 叙事性判断 + "已停滞几拍"软信号。

### 量子挪移的边界
- **只用于"导航/地点"选择**（走哪条走廊无所谓，挪）。
- **绝不用于"后果性叙事"抉择**（结盟 A/B、救城/弃城）——那是 `branchPoint` 或真分叉。**故事抉择是真的，路线选择可以是假的。**

### 运行时进度状态
- **里程碑游标** `{ currentMilestone, completed[], discoveredLeads[] }`；完成由 AIDM 判定并写状态；**每分支各一份**（[ADR-0004/0005]）。
- **世界时钟**：具名分段进度轨；**默认隐藏**（玩家只通过剧情感受风险，不见数字），AIDM 可叙事性外显体感。

### Campaign genesis
- 默认**轻种子 + AI 充实**（前提 + 基调 + 高潮 + 等级区间 → 粗骨架），保留一键全自动 / 人工撰写。
- **开团者默认盲盒**：AIDM 秘密创作暗线，owner 作为真正玩家入场（贴合"我想玩、不想当 GM"的立项动机）；保留"剧透/共创"开关。
- owner 仍握 merge/人格审阅的**元层控制**（[ADR-0004]），但剧情暗线对作为玩家的他**是盲的**——元层有权、故事层无知，并存。

## 备选

- **铁轨（预写死场景）**：与涌现/自治系统正面对冲，偏离即硬掰。否决。
- **纯目标集/沙盒**：长弧易散、"忠实剧本"几乎不剩。否决。
- **禁止量子挪移**：导航是真的、但作者内容易被绕过、长弧易走散。否决（用户选保住内容）。
- **可见进度条时钟**：更游戏化、张力外显，但偏离"叙事优先"基调、且玩家会"看表卡 BUG"。否决，选隐藏。
- **开团者剧透/共创为默认**：掌控感强但自己玩没悬念。否决，选盲盒默认。

## 后果

- 脊柱结构 = 未来模组导入的现成靶子。
- 量子挪移被用户接受，但边界（仅导航）保住了后果性抉择的真实能动性。
- 盲盒默认要求 AIDM 能独立创作可玩的暗线——加重 AIDM 创作负担，但符合产品定位。
