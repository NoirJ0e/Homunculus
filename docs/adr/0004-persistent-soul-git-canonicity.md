# 4. 持久灵魂：git 式 canonicity + 两层记忆 + 受护栏的人格演化

- 状态：Accepted
- 日期：2026-06-01

## 背景

pillar 2 要"持久个性"。真实的 DND 玩家会带着角色跨模组成长（凡达林矿坑→阿弗纳斯……），卡不死就该继承。但"持久"含两种不同的东西：**成长/面板**（无副作用）与**自传体记忆**（跨世界/跨系统硬流过去会精神错乱）。且若面板无条件成长，会出现"10 级却没有变强记忆"的叙事断裂。

## 决策

- **跨桌持久灵魂**：灵魂 = 成长(面板) + 自传体记忆 + 人格核心。
- **成长 + 记忆 + 人格演化捆在同一个 canonicity 开关**上一起动（不拆开，避免叙事断裂）。
- **git 模型，开局只 fork、收尾才终判**：
  - 每场默认在灵魂当前 canonical HEAD 上 **fork 一条分支**（廉价、可反悔）。
  - 收尾选 **merge**（成长+记忆+人格+死亡一并并入本体）或 **discard**（什么都没发生，连撕卡死亡都不生效）。
  - 主线 campaign 是长期分支，逐段持续 commit；支线/练手/what-if 是 fork，收尾决定。
- **两层记忆**：① 常驻人格核心（小、稳、永远在上下文，防失忆/OOC）；② 情节记忆库（按需召回，老情节定期巩固/摘要）。**记忆写入归属当前分支**，与 canonicity 一致。
- **人格全演化 + 护栏**：反思 pass（场景收尾离线跑）可演化人格（贵公子经历生死团战后软化），但护栏防止坍缩成千篇一律的和善 assistant：
  - 每处改动**必须引用具体亲历事件**（无证据不改）；
  - 核心性情**高惯性**（一场改不了，多场才行）；
  - 人格改动作为 diff 累积在分支上，**merge 时作为"人格变更日志"摆到 owner 面前，可逐条否决**；
  - 每次 merge 提供一个**"这次放手，你自己看着办"**的开关（可跳过审阅、全自动并入）。

## 备选

- **Campaign 内持久（记忆不跨桌）**：实现简单，但不满足真实 DND saga。否决。
- **成长无条件 + 记忆有条件**：造成"无记忆的强者"叙事断裂。否决（用户当场反驳）。
- **开局锁定 canon**：脆——无法预知练手本跑出神剧情、或正史团跑崩想 retcon。否决。
- **人格内核锁死（只增关系账）**：绝对稳定但缺成长弧，会让贵公子永远 OOC 地端着。否决，选全演化 + 护栏。

## 后果

- discard 的练手本不改变灵魂本体；只有 canonical 团塑造它。
- 人格漂移可审计、可否决，但 owner 也能一键放手。
- 依赖 SealDice 分支快照垫片（[ADR-0001]）来让卡的成长随分支走。
