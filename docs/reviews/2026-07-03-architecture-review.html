Problem — card-creation module 的 interface 承诺一条草稿管线（holdSoulDraft → drafts → verify 消费），纯函数 holdInitialDrafts 建成且测试全绿——但生产路径零调用（grep 证实：只有测试在调）。开卡向导只是普通对话 query，玩家聊 30 分钟的人设无处落；/verify-card 永远在审 genesis 兜底卡。这是「为可测试性抽出纯函数、真 bug 藏在没人调用它」的教科书案例：每个 module 各自绿，组合流程断路，无 locality。

Solution — 沿用全仓一致的范式（能力 = 进程内工具）：给开卡向导挂一个 hold 草稿的工具，工具 handler 调 holdInitialDrafts；genesis 兜底降级为真正的例外分支。

  • interface 变诚实：drafts 真的会被填
  • 端到端可测：假工具调用流直通 verify
  • 审卡审的是玩家聊出的卡，不是模板
ADR 关系：read-card-under-review.ts:11 自己标了「v1 留白」——本候选是偿还 ADR-0012 Phase 5 的已挂账债，与 ADR-0009「能力=工具边界」同构，无冲突。它兼具 live bug 性质：现在就影响每一次真实审卡。

Problem — 五个 deep、已单测的内核（记忆召回、反思 pass、canonicity、兵分两路、软引力）在 src 里零生产调用。不是它们 shallow——是拍循环没有它们能插的 seam：Referee 的 ctx() 没有 recall 注入口，没有「场景收尾」的生命周期时刻，没人累计 stallBeats。ADR 把设计写完了，代码在等一个插座。

Solution — 不是「把所有东西都接上」（那是 roadmap），而是给拍循环开一个具名的灵魂生命周期 seam：拉起时注入召回、收尾时写记忆/跑反思、轮状态里养 stall 计数。接哪个、何时接，逐切片决定。

  • 「recall 即替换点」（ADR-0008）真正成立
  • 端到端测试终于有路径可走

Problem — 每个 slash 命令 = 一个文件 + 一个工厂 + main 里一段专属 DI。pause(26)/approve(44)/check(73) 是纯转发；deletion test 结果混合：薄的删掉合并复杂度消失，厚的（add-ai-seat 编排 genesis→审→改→绑）在挣位置。伤害主要落在组合根：新命令要动 command-set + main + handler 三处，回复通道还是个可变单例。

Solution — 命令面收成一个 module：声明式表 + 一次装配的共享上下文；薄命令变表行，厚命令保持独立 module。

  • 新命令 = 表加一行，main 不再膨胀
  • 权限与回复上下文获得 locality
  • 删 3–4 个纯转发文件

标 Speculative 的原因：现状每个 handler 都有测试、伤害有限；收拢主要买 main.ts 可读性。若候选 1 先落地，main 瘦身后此卡收益再评。ADR-0012「slash=控制面」不受影响。

健康、不需要动

  • pacing / combat-round / controller / roster — deep 纯内核，interface 清晰
  • mapContentToTurn — 内容约定正确集中（ADR-0011）
  • dm-driver / dispatcher / push-inbox — 测试从 interface 进入
  • DicePort：BCDice + NativeDice 双 adapter = 真 seam（ADR-0013）
  • substrate：单 webhook / 多 bot 池双 adapter = 真 seam
  • genesis 内核（soul / campaign）— deep、确定性、已测

克制不做（一个 adapter = 假想 seam）

  • transport 无关的 persona 抽象（走查建议过）：VTT 是 pillar-1、明确延后；现在只有 Discord 一族 adapter，为假想基底开 seam 违反「两个 adapter 才是真 seam」
  • NPC prose 防工具语法注入：无实证摩擦，先不设防
  • SceneBook 虽是薄封装，但 locality 无伤——caller 只有 Referee 一个，不动

Top recommendation

先做 候选 1：牌桌装配

最近八个 commit（#50–#57）全在接线层修 live bug，而接线配方恰好抄了三份、且整块自外于测试。把它收进一个 deep module 是本仓库「测试面 = interface」收益最大的一刀：装配大半是确定性组合，假 port 即可覆盖，脚本从此跑的就是生产接线。候选 3（拍回执）与候选 4（生命周期挂点）都围着装配好的 Referee 生长——这一刀先落，后面两刀有落点。候选 2 是例外：它是正在发生的 live 断路，切口小，可以并行先修。
